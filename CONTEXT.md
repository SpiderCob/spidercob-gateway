# Spidercob Gateway — Current State

**Read this first in a new session with no memory of prior conversations.** For the full plan and rationale, see `MASTER_PLAN.md` and `docs/design.md` on `main` — this file is a rolling snapshot, not a replacement for those. It lives on this orphan branch (`context_main`) deliberately, separate from `main`'s code history — nothing to check out here, just a doc to read. See `CLAUDE.md` on `main` for the update procedure and why this is a different thing from any future domain-glossary `CONTEXT.md`.

## What this is

Open-source MCP gateway: spec-correct agent identity (ID-JAG / MCP Enterprise-Managed Authorization) plus policy and DLP, in one container. Launches together with **spider-snoop** (the parent Spidercob product) as one integrated product, not two separate logins. Full north star: `MASTER_PLAN.md` §0 on `main`.

  - **[PR #27](https://github.com/SpiderCob/spidercob-gateway/pull/27)**: fixed the PR #26 finding directly — `TestListAuditRecordsPage_OverLargeLimitClamped` seeded too few rows to actually exercise the clamp it claimed to test; fixed and verified the fix catches a real broken-clamp regression.

    - **[PR #28](https://github.com/SpiderCob/spidercob-gateway/pull/28)** (auth-path/config): `idptrust.Validate` now enforces `exp`/`jti`/`sub` presence on external ID-JAG assertions — closes a **real panic risk** (`handleJWTBearer` dereferenced `claims.ExpiresAt.Time` unconditionally). Bearer-token parsing is now case-insensitive/whitespace-tolerant (RFC 7235/7230). The Mode A session cookie now sets `MaxAge`/`Secure` correctly. Default `Issuer` construction no longer breaks for non-bare-port `listen` values. `config.ValidateNode`'s charset now actually matches its own doc comment (`[A-Za-z0-9._-]+`, was letting spaces/`%`/`?`/`#` through).
    - **[PR #29](https://github.com/SpiderCob/spidercob-gateway/pull/29)** (runtime robustness): `store.DeleteGroup` TOCTOU race fixed with a real transaction (reproduced the bug 3/3 times before fixing it). `pin.Scheduler` now bounds each node's fetch with a timeout, closing a real `Stop()` deadlock risk. `webui.Handler()` no longer falls back to a directory listing when the UI hasn't been built. `scan.PIIScanner` redaction switched to byte-safe `ReplaceAllFunc` — **with a correction worth knowing about**: the original review comment's specific claim ("converting to a Go string and back corrupts invalid UTF-8 bytes") was checked directly with a standalone Go program and does **not** actually hold — a bare `string([]byte)`/`[]byte(string)` conversion in Go never validates or substitutes UTF-8. The code change was kept anyway (real efficiency + consistency-with-`SecretScanner` wins, both legitimate), but the comments/commit message state the corrected rationale, not the original false one. `audit.GenesisPrevHash` is now a real `const`, not a mutable exported `var`.
  - **Every Tier 1 fix was verified with a genuine red→green cycle**: the fix was temporarily reverted, the new test was confirmed to actually fail, then the fix was restored and confirmed green again — not just "wrote a test, it passes against the fixed code."
  - **`MASTER_PLAN.md` was deliberately NOT updated for PRs #27/#28/#29** — these are direct bug fixes from automated code review, not a new Phase 4 slice in the roadmap sequence. Worth knowing so a future session doesn't wonder why the plan doc doesn't mention them.
